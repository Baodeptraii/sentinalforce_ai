## Restore / deployment notes

1. Create the GUI and Scenario virtual environments separately, using their project dependency files.
2. Restore the required corpus and rebuild the catalog/RAG index using Scenario scripts. Generated databases were not backed up in this source export.
3. Create private configuration from examples; set the actual `scenario_root`, credentials-file paths, authorized networks, CALDERA and Wazuh endpoints. Examples are templates and may contain old lab addresses.
4. Reconfigure the user service and external credentials on the destination host. Secrets and live service configuration remain on the original host.
5. Run offline tests and fresh preflight before any lab execution. Several historical regression tests depend on lab fixtures not distributed in Git.

The source matches the reporting/dashboard work reviewed on 27 November. Known limitations remain: Survey telemetry is disabled in the live configuration, fixed cases are deterministic rather than LLM-generated, behavior-specific detection is not yet verified, and a new end-to-end execution after reporting updates remains to be tested.
